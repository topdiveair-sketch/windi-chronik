# Windi-Chronik – zentrale Speicherung

## Installation
1. Den Inhalt des Ordners `SERVER_AUF_WEBSERVER` auf einen PHP-Webserver kopieren, zum Beispiel nach `https://deine-domain.at/windi-api/`.
2. In `config.php` den Redaktionscode `WINDI-2026` ändern.
3. Im Verwaltungsbereich der App unter **Daten** als Serveradresse `https://deine-domain.at/windi-api/api.php` eintragen.
4. Den gleichen Redaktionscode eintragen und **Verbindung speichern und testen** drücken.

Danach landen Gastbeiträge zentral im geschützten Redaktionsbereich – unabhängig vom Gerät.

Hinweis: GitHub Pages führt kein PHP aus. Dafür ist ein normaler Webspace mit PHP nötig.
