# Windi-Chronik Android-Projekt

## APK in Android Studio erstellen

1. Android Studio installieren.
2. Diesen Ordner über **Open** öffnen.
3. Warten, bis Gradle und das Android-SDK geladen wurden.
4. Menü **Build > Build APK(s)** wählen.
5. Die APK liegt danach unter:

`app/build/outputs/apk/debug/app-debug.apk`

## Eigenschaften

- App-Name: Windi-Chronik
- Paketname: `at.zuhauseambach.windichronik`
- Android ab Version 8
- Offline nutzbar
- lokale Datenspeicherung auf dem Handy
- Fotoauswahl aus der Galerie
- Gastbeiträge, Redaktion, Chronik und Jahresbuch
- keine externe Website nötig

## Wichtig

Die erste APK ist eine lokale Einzelgeräte-Version. Damit Gäste auf ihren eigenen Handys Beiträge einreichen und diese bei Hans ankommen, braucht die nächste Version einen gemeinsamen Online-Server oder eine Datenbank.
